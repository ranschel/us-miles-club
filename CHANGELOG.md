# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-25

Initial public release.

### Added
- Interactive US map with county- and state-level choropleth, legend, and hover detail.
- Leaderboards ranking by state, county, and city, filterable by sport.
- Sport filter for walk, run, and bike across the map and boards.
- Badges for milestones such as first mile logged, the 10 Mile Club, county coverage, and best daily streak.
- Monthly goal setting with progress tracking.
- Personal insights breaking down individual logging patterns and totals.
- Shareable rank card export.
- Data transparency panel explaining what is counted and how.
- Light and dark themes that follow system preference, with a manual toggle.
- Public map, leaderboards, and about pages readable without an account.
- Supabase-backed authentication, workout logging, and row-level security.
